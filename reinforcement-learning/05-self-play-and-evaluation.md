# 自己対戦と評価

教材: AlphaStar の論文（Nature 2019）のリーグの節、ptcg-abc の `docs/research/solutions/survey.md` 4.2節・4.3節・6章、`docs/recap/ptcg-devenv-rl-retrospective/05-opponents.md` と `08-evaluation.md`

## この章で説明できるようになること

- 自己対戦で学ぶときに、誰を相手にするかの選択肢を挙げられる
- 非推移性（じゃんけんのような関係）が何を壊すかを説明できる
- 強さを測るための条件（相手、試合数、席、シード）を挙げられる
- 学習の相手と評価の相手を分ける理由を説明できる

## 1. 自己対戦

- 今の自分と戦う
- 過去のスナップショット（凍結した自分）を混ぜる
- 固定のルールベースを混ぜる
- それぞれで、何が学べて何が学べないか

## 2. リーグと exploiter

- PFSP（自分の勝率に応じて相手を選ぶ重みを変える。重みの付け方で、負けている相手を優先するか、勝率が五分に近い相手を優先するかが変わる）
- exploiter（特定の相手を狙って倒す方策を育てる）
- 上位チームの採用例（`survey.md` 4.2節）

## 3. 非推移性と忘却

- A が B に強く、B が C に強く、C が A に強い関係
- 過去の自分に負けるようになる現象
- 凍結した方策への KL ペナルティ（4位、9位、12位、13位、14位）

## 4. 強さをどう測るか

- 固定の比較対象、共通のシード
- 席（プレイヤー0とプレイヤー1のどちらに座るか）の入れ替え
- 先攻・後攻の偏りの確認（24位の rating arena では、席とゲーム内の先攻・後攻は別に決まる）
- 必要な試合数と信頼区間（1位は「相手ごとに500局以上」、13位は「数万局でも有意差には2〜3pt必要」）
- レーティング（Elo、TrueSkill、Bradley–Terry）
- 対面ごとの退行の確認

## 5. 学習の相手と評価の相手を分ける

- 学習の相手への勝率が上がっても、強くなったとは限らない
- 相手への過学習（教師あり学習で、学習データと検証データを分ける話と同じ構図）
- 床（弱い相手）と天井（強い相手）のプールを分ける
- ptcg-devenv の実例（汎用エージェントに勝てても、公式サンプルには勝てない）
