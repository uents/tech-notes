# 方策勾配法

教材: Sutton & Barto 第13章（方策勾配法）、OpenAI Spinning Up の "Intro to Policy Optimization"

## この章で説明できるようになること

- 価値ベース（Q 学習）と方策ベースの違いを説明できる
- 方策勾配の式が「何の期待値」なのかを説明できる
- ベースラインと advantage が、なぜ分散を下げるのかを説明できる
- GAE の λ が何を調整しているかを説明できる
- 合法手が可変長のゲームで、方策をどう表すかを説明できる

## 1. 方策を直接学ぶ

- 目的関数 J(θ)（方策 π_θ で対戦したときの期待リターン）
- 価値ベースとの違い（Q の最大値を取るのではなく、手の確率そのものを動かす）
- 確率的な方策の利点（不完全情報ゲーム、探索）

- ベースライン b(s) を引いても偏りが出ない理由
- advantage A(s, a) = Q(s, a) − V(s) の意味

## 4. GAE（一般化 advantage 推定）

- 1ステップ TD と、エピソード全体のリターンの間を取る
- λ の役割（偏りと分散のつり合い）
- 24位の設定は λ = 0.99。5位は「1ターンに約10.8判断あるので λ = 0.95（このターンと相手の返しまで）が 1.0 より良い」と報告している

## 5. エントロピー正則化

- 方策が早く決め打ちになるのを防ぐ
- 係数を大きく／小さくすると何が起きるか
- 24位の設定は 0.01

## 6. 合法手が可変長のときの方策

- 固定の行動の表を持たず、合法手を1つずつ採点する（ポインタ型）
- 合法でない手を確率0にする（マスク）
- 複数枚を選ぶ判断は、1枚ずつ選んで STOP で終える（自己回帰）
- 上位チームのほぼ全員がこの形だった（ptcg-abc の `survey.md` 3.1節）
